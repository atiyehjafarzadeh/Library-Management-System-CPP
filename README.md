# Library Management System

## Overview

This project is a console-based Library Management System implemented in C++. It allows librarians to manage members and books, handle borrowing and returning operations, and store data using text files.

## Features

* Add new library members
* Add new books
* Borrow books
* Return books
* Check member and book availability
* Save and load data from files

## Technologies Used

* C++
* STL (Vector, Algorithm)
* File Handling
* Object-Oriented Programming Concepts

## Data Storage

The system stores information in text files:

* members.txt
* books.txt

## Future Improvements

* Search functionality
* Delete and edit records
* Borrowing history tracking
* Graphical User Interface (GUI)
